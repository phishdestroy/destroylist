## Downloads

| Format | Description | Link |
|:-------|:------------|:----:|
| `domains.txt` | Plain domain list | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/domains.txt) |
| `hosts.txt` | Hosts file (`0.0.0.0 domain`) | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/hosts.txt) |
| `adblock.txt` | AdBlock / uBlock Origin filter | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/adblock.txt) |
| `dnsmasq.conf` | DNSMasq / Pi-hole config | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/dnsmasq.conf) |
| `unbound.conf` | Unbound DNS config | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/unbound.conf) |
| `rpz.zone` | Response Policy Zone (BIND) | [Download](https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/formats/primary/rpz.zone) |

> Includes all curated domains (live + dead). For live-only, use [`primary_active/`](../primary_active/)
