## What Is This?

The full blocklist split into numbered JSON shards (`part_000.json` — `part_033.json`), each containing up to 3,000 domains as a flat array.

Designed for:
- **CDN edge caching** — small files load fast globally
- **Pagination** — fetch one shard at a time
- **Browser extensions** — avoid loading 100K+ domains at once
- **Rate-limited APIs** — process in batches

<img src="https://user-images.githubusercontent.com/74038190/212284100-561aa473-3905-4a80-b561-0d28506553ee.gif">

## Usage

```bash
# Fetch a single shard
curl -s https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/arrays/part_000.json

# Fetch all shards
for i in $(seq -w 0 33); do
  curl -sO "https://raw.githubusercontent.com/phishdestroy/destroylist/main/rootlist/arrays/part_0${i}.json"
done
```

## Schema

Each file is a plain JSON array:

```json
[
  "example-phish.com",
  "scam-domain.net",
  "fake-wallet.xyz"
]
```
