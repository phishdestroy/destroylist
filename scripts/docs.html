⚙️ Automation & Schedules

📋 On List Update
trigger: push to list.json, dns/*, community/*
Validates JSON → cleans against allowlist → converts to all formats → updates counts → builds rootlist + shards → commits
event-driven
🔄 Scheduled Update
cron: every 15 min
Runs DNS validation via active_domains.py, builds rootlist. Keeps live/dead domain status current.
every 15 min
📊 Update Statistics
cron: 0 */6 * * * (every 6 hours)
Recalculates stats from all lists. Updates stat badges and count endpoints.
every 6h
🌐 Deploy GitHub Pages
cron: 0 */3 * * * (every 3 hours)
Rebuilds and deploys the PhishDestroy website via Jekyll.
every 3h
🔗 Check Links
cron: weekly + on push to .md files
Validates all links in markdown files across the repo.
weekly
🧹 Stale Issues
cron: 0 6 * * * (daily 06:00 UTC)
Labels issues/PRs inactive for 60 days as stale. Closes after 14 more days. Excludes: pinned, security, appeal.
daily

🔧 Processing Pipeline

When domains are added to list.json, the On List Update workflow triggers this pipeline:

1. validate_json.py
Validates JSON structure of all list files
2. validate_and_clean.py
Removes false positives using allow/ lists
3. json_to_txt.py
Converts JSON → 6 output formats (hosts, adblock, dnsmasq, unbound, rpz, plain)
4. update_counts.py
Updates count.json badge endpoints for shields.io
5. build_rootlist.py
Extracts root domains via tldextract, filters infrastructure, validates DNS
6. build_shards.py
Splits root domains into 34 JSON array chunks (3K each)
